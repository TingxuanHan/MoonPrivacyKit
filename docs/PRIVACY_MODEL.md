# 保护范围与信任边界

随机响应保护的是已声明类别中的回答内容。它不隐藏参与调查的事实、IP、浏览器特征或其他网络元数据；也不防止恶意客户端代码在随机化前读取答案。客户端及其分发渠道必须受信。

多题回答需要组合核算。重复参与、跨版本采集和不同设备上的提交需要额外的贡献限制；本地工具不宣称能在不识别用户的情况下强制限制所有重复参与。

真实回答与随机数不应进入提交负载、日志或导出报告。随机化必须使用不可预测的安全随机源。固定种子的随机数只适用于模拟与测试。

比例估计存在抽样和随机化误差。误差界不覆盖不诚实回答、恶意灌票、选择偏差或非独立随机数造成的失真。小样本下可能无法获得有用结论。

字段删除或遮盖是数据最小化措施，不具有自动的差分隐私保证，也不能保证消除所有重新识别风险。需要由使用者选择字段并复核输出。

首期工作台采用本地处理，不配置外部统计脚本或远程数据上传。在线问卷服务、身份隔离与部署审查属于后续工作。

中心化统计核心在可信数据持有者侧运行。以增加或删除一个人的全部记录为相邻关系，按稳定人员标识限制整次查询中的贡献，再发布整数噪声保护的计数或预设类别直方图。类别和参数应事先确定；空数据及零计数类别同样加噪。核心不把真实人数、贡献裁剪数量或人员标识写入结果。

调用方须确保同一个人的标识一致、预处理不改变其他人的记录。通过[发布账本](RELEASE_LEDGER.md)调用时，预算与结果在同一事务中保存，同一请求复用已有结果；直接调用无状态核心时则需自行记账。原始数据访问、输入验证错误、耗时和其他侧信道不在统计输出保证内。具体机制、误差与使用条件见[中心化隐私统计](CENTRAL_PRIVACY.md)。

本地账本依赖可信持有者正确界定保护范围并保留最新历史，不能防止有权修改文件的人删除、复制或回滚账本。不同工具或数据版本涉及相同保护对象时，应沿用仍适用的发布开销，不能靠新建文件重置预算。账本不是加密数据库，包含请求绑定信息与本地密钥，不应当作可公开的统计报告。

# 保护范围与信任边界

## 新增工具的保护边界（2026-10-16）

报表防反推只覆盖用户声明的同群体精确整数约束，计算超限或矛盾时不作安全判断。候选比较与两版联查输出精确私有指标，仅供可信持有者复核；分组指标不是匿名认证。根据私有数据选择的方案不能直接沿用预设规则的 DP 保证。原表不自动备份。

按人多表统计以同一标识表示同一个人在两表中的全部记录，连接前后均限制贡献，有界整数和按公开上界校准。标识真实性由持有者负责；当前不支持任意连接。上游预算核验与本地 SQLite 共用同一精确余额，不引入可独立重置的第二个账本。

匿名参与凭证使用统一调查配置和盲签名分离资格核验与兑换。资格限额针对经组织者验证的账号，不自动等价于真实自然人；同一凭证只绑定一份受保护回答，重复请求返回同一回执。仍可能通过 IP、时间、问卷内容或不同公共配置关联身份，公共配置和传送渠道需可信。私有凭证与密钥不作页面预览，角色数据库不等于加密存储。

联合统计采用两个独立聚合方的加法份额、加密传输文件与签名合计。安全模型要求参与方按协议执行，至少一聚合方不与另一方串通；持有两方密钥会失去分离保护。签名不是输入范围证明，全员固定批次也不防止跨任务差分攻击。精确合计没有 DP，结果开放必须另行设计。回环服务用于本地角色部署和验证，公网 TLS、身份系统、恶意安全及独立审计未完成。

随机响应保护的是已声明类别中的回答内容。它不隐藏参与调查的事实、IP、浏览器特征或其他网络元数据；也不防止恶意客户端代码在随机化前读取答案。客户端及其分发渠道必须受信。

多题回答需要组合核算。重复参与、跨版本采集和不同设备上的提交需要额外的贡献限制；本地工具不宣称能在不识别用户的情况下强制限制所有重复参与。

[问卷模板](SURVEY_TEMPLATES.md)复用题目、选项、ε 和计划次数，不包含回答或原问卷编号。每次应用创建新配置身份，仅用于避免误混不同调查的响应；不重置同一人的历史隐私开销。采集计划和参与说明不是实际参与账本，也不自动与中心化统计账本合并。说明按经过校验的配置生成并标注指纹；指纹不验证发起者身份，计划次数也不是已实施的参与限制。随机化有可能输出原选项，不能把“不附带原始选择”理解为“选项必然改变”。

真实回答与随机数不应进入提交负载、日志或导出报告。随机化必须使用不可预测的安全随机源。固定种子的随机数只适用于模拟与测试。

比例估计存在抽样和随机化误差。误差界不覆盖不诚实回答、恶意灌票、选择偏差或非独立随机数造成的失真。小样本下可能无法获得有用结论。

[逐题精度评估](SURVEY_ASSESSMENT.md)只读取问卷配置与预计人数，不读取回答、不随机采样、不访问发布账本。其 95% 同时范围针对单次采集的全部题目与选项，不保证全部重复批次同时覆盖。人数按每次采集计算，重复次数只增加计划隐私开销。报告包含问卷标题、问题标题和配置指纹，配置文本中不应写入个人信息；指纹只绑定配置，不证明身份或实际执行次数。规划报告不是实际参与记录或发布预算凭证。

[可读报告](READABLE_REPORTS.md)只转换已有结果，不随机采样、重新统计或操作账本。仅接受明确的结果类型与已知字段，数值和维度须一致；拒绝夹带未知字段，但格式检查不证明报告来源、真实性或机制被正确执行。HTML 不嵌入原始 JSON、个人回答、人员标识、项目名、账本余额或请求身份；标题、选项和公开类别仍由使用者复核。所有动态文本转义，文件不含脚本或远程资源；来源参数和保护说明随结果保留，统计报告中的本次 ε 不代表剩余预算。

字段删除或遮盖是数据最小化措施，不具有自动的差分隐私保证，也不能保证消除所有重新识别风险。需要由使用者选择字段并复核输出。

[泄露实测](PRIVACY_ATTACK_AUDIT.md)以可信持有者提供的成员、独立对照与固定发布开展内部攻击实验。人员标识只用于去重、跨组排重与可复现拆分，不作为预测特征或报告内容；数据不向服务上传，不写浏览器存储。校准数据与测试数据按人分开，测试集不参与阈值选择。真实成员关系、同人标识和人群可比性不能由代码验证；区间仅近似描述既定设计下的测试比例，攻击失败不证明安全。报告依赖私有数据，不属于 DP 后处理；公开报告或按其分数选择输出，需要另行处理隐私开销。评估不调用发布或重置预算。

首期工作台采用本地处理，不配置外部统计脚本或远程数据上传。在线问卷服务、身份隔离与部署审查属于后续工作。

问卷、脱敏与效果评估只在浏览器中处理；隐私统计在发布时向回环地址的本机服务发送本次统计源表（直接导入或经字段处理后转入），服务通过持久账本保存受保护结果和预算。源表、字段映射和人员标识不写入应用日志或账本。浏览器会话存储只保存所选项目与待确认请求编号，不保存表格、发布配置或服务令牌。数据持有者必须信任浏览器、页面代码和本机服务。

本机统计接口限制监听地址、Host、同源 Origin、Fetch Metadata 和会话令牌，拒绝任意文件路径和未列出的操作。会话令牌用于隔离其他网站请求，不是多用户登录或抵抗本机恶意程序的机制；账本及接口中的余额、项目名和输入错误仅供持有者使用。不得直接把这个本机服务改为公网或共享网络服务。具体数据流见[本地统计工作台](LOCAL_WORKBENCH.md)。

中心化统计核心在可信数据持有者侧运行。以增加或删除一个人的全部记录为相邻关系，按稳定人员标识限制整次查询中的贡献，再发布整数噪声保护的计数或预设类别直方图。类别和参数应事先确定；空数据及零计数类别同样加噪。核心不把真实人数、贡献裁剪数量或人员标识写入结果。

调用方须确保同一个人的标识一致、预处理不改变其他人的记录。通过[发布账本](RELEASE_LEDGER.md)调用时，预算与结果在同一事务中保存，同一请求复用已有结果；直接调用无状态核心时则需自行记账。原始数据访问、输入验证错误、耗时和其他侧信道不在统计输出保证内。具体机制、误差与使用条件见[中心化隐私统计](CENTRAL_PRIVACY.md)。

[真实表格统计](TABLE_STATISTICS.md)通过明确的字段映射提取人员标识和预设类别，逐行校验后交给账本发布。映射只按原样取值，不猜测类别、不自动生成身份、不按其他人的数据调整记录。私有中间数据只在内存中使用；报告和账本不保存原始标识或未选中的字段。字段删除与按人统计的输入要求不同，不能将人员标识删除后仍视为具备可靠的贡献限制。

本地账本依赖可信持有者正确界定保护范围并保留最新历史，不能防止有权修改文件的人删除、复制或回滚账本。不同工具或数据版本涉及相同保护对象时，应沿用仍适用的发布开销，不能靠新建文件重置预算。账本不是加密数据库，包含请求绑定信息与本地密钥，不应当作可公开的统计报告。

[统计模板](STATISTICS_TEMPLATES.md)只复用字段映射、公开类别、贡献上限和单次 ε，不携带原表、账本或请求身份。模板兼容性检查读取本地记录，但不采样、不记账，也不返回私有值；检查结果只供可信持有者使用。字段类型通过检查不代表真实人员标识正确，模板导入不会替用户确认类别是否独立于私有数据设定。使用模板的新发布仍需累计核算相关开销。

[字段模板及统计衔接](FIELD_WORKFLOWS.md)要求明确配置全部列，新增字段不能被旧模板静默保留。工作台与 `publishRedactedRelease` 要求人员标识明确保留且未改写，类别可使用未改写或通过年龄／日期规则泛化的列；排除已删除、遮盖及 CSV 公式文本化改变的列。这不能验证自然人身份真实性。处理后的明细和兼容性信息仅供可信持有者使用，不是公开统计报告。转入不恢复被删除字段、不创建发布编号、不更换账本；原文件、规则或统计设置变化后，不得以工具切换为由清空历史开销。单独下载再导入的文件没有可信处理历史，不能从列类型推断其语义保持不变。

[年龄分段与日期降精度](FIELD_GENERALIZATION.md)按公开配置逐行处理，不调整其他人的记录、不删除无效行、不依据私有值推断范围。无效或缺失值阻止整份处理；错误与精确处理数量仅供可信持有者查看。分段起点、日期精度及统计类别须独立于私有数据事先确定；系统不自动证明这一条件。年龄段、月份和年份不能作为人员标识。泛化本身不提供差分隐私保证，也不能消除关联重识别风险；仍需通过受控账本发布受保护统计输出。

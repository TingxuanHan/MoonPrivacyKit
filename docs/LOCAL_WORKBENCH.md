# 本地统计工作台

在仓库根目录运行 `npm run build`、`npm start`，打开 http://127.0.0.1:4173 并进入“隐私统计”。该入口将现有表格映射、中心化差分隐私机制和发布账本连成页面流程，不需要手工编写发布请求。

## 第一次生成报告

1. **建立统计项目。**填写用途明确、不含个人信息的项目名称，确定总预算 ε。名称支持 1 至 60 个中文、字母、数字、空格、短横线或下划线。总预算支持 0.01 至 1000、最多六位小数；这是预先确定的发布上限，不是推荐的安全值。已经涉及同一批人的分析应沿用已有项目，并考虑其他渠道发生的相关发布开销。
2. **导入表格。**选择不超过 4 MB 的 UTF-8 CSV／JSON 文件。界面仅列出字段，不预览个人记录；也可载入虚构示例熟悉操作。统计要求见[表格统计](TABLE_STATISTICS.md)。页面需要可选择的列名，因此空数据使用保留表头的 CSV；空 JSON 数组仍可通过命令行使用明确映射发布。
3. **设置统计。**计数需要稳定的人员标识列；类别分布还需要类别列和事先确定的公开类别。每人贡献上限为 1 至 32，本次 ε 为 0.01 至 8、最多六位小数。上限为 1 的计数估计不同人员数；上限更大时为按人裁剪后的记录数。直方图对全部类别共同限制每人贡献，不是每个类别各有一个上限。
4. **评估并发布。**页面根据参数显示误差界，预估不读取个人记录、不消耗预算。点击标明本次开销的“生成报告”后，表格发送到当前地址的本机服务；服务先校验输入和预算，保存受保护结果后才返回报告。重复点击被阻止，同一请求重试复用已保存结果。
5. **查看与下载。**图表只展示受保护计数、公开类别和误差范围；不显示真实人数、裁剪数量、人员标识或原始明细。下载的是账本保存的同一份 JSON 报告，重复下载不取样、不扣减预算。若需要新统计，点击“准备下一次发布”，核对参数后另行发布。

误差范围针对贡献裁剪后的统计量，不包含裁剪偏差、样本偏差或错误身份映射。小样本的随机误差可能远大于真实统计量，不能根据 0 推断无人参与。类别定义须独立于私有数据预先确定；未知类别或字段错误会拒绝整个输入，不静默丢弃。

## 历史报告与中断恢复

项目显示剩余、已用和总预算，以及保存的报告数量。历史按每页 20 份列出，支持加载更早记录、查看和下载；这些操作不增加开销。多个窗口或命令行产生新发布后，使用“刷新项目”或“刷新历史”获取最新记录。

| 当前情况 | 应如何处理 |
| --- | --- |
| 报告已保存，只是下载失败 | 再次下载，或从历史打开原报告 |
| 发布时断开连接，不确定是否完成 | 先点击“恢复已保存报告”，或用原输入“重试本次发布” |
| 发布后刷新页面 | 进入隐私统计，页面根据保留的编号尝试恢复；不重新采样 |
| 刷新后尚未找到报告 | 原发布可能未完成。保留编号，稍后恢复，或重新选择原文件和原设置重试 |
| 相同编号出现不同输入 | 保留现有记录，恢复原报告；不自动改用新编号 |
| 明确的输入错误或预算不足 | 未产生新报告；修正输入或查看已有结果。未确认的旧请求仍保留原编号 |
| 关闭页面导致恢复编号丢失 | 重新选择原项目，从历史查看已保存结果；先确认历史，再决定是否新发布 |

在待确认状态下不能切换项目或新建项目。当前页面保留原表时会锁定原配置；刷新后只允许重新提供输入以重试原编号，不保存原始文件的副本。预算与结果同时提交，页面显示或文件下载失败不能当作发布没有发生。

## 存储与运行边界

- 默认账本目录为仓库内 `private-data/workbench/`，每个项目一个 `.sqlite` 文件，SQLite 按事务需要管理临时日志。该目录被 Git 忽略，不应公开；账本不是加密数据库。
- 可在启动前设置环境变量 `MPK_DATA_DIR` 指定受控目录。更换目录不会迁移已有历史，不能借此为同一保护对象重新计费；保留相关的最新账本。页面不提供任意文件路径、删除、扩额或重置预算的接口。
- 本机服务不保存原表、字段映射或人员标识；保存受保护报告、整数预算、请求编号及带密钥的绑定摘要。项目名称、账本元信息和输入错误不是可以直接公开的差分隐私结果。
- 浏览器 `sessionStorage` 只保存所选项目标识和待确认请求编号，方便刷新恢复；不保存原表、配置或会话令牌。原表和本次输入只存在于页面及本机服务内存中，关闭页面后需重新选择。操作系统自身的交换文件、浏览器扩展和本机恶意程序不在这一应用存储约定的保证范围内。
- 问卷、字段处理和效果评估仍在浏览器内处理；它们不向本机统计接口发送文件。所有工具均不加载外部资源或向远程服务上传数据。

## 本机接口限制

服务器只监听 `127.0.0.1`。固定程序资源之外，统计接口仅接受项目创建、状态查询、表格发布和历史读取。请求校验本机 Host、同源 Origin、Fetch Metadata 与随机会话令牌；写入还要求 JSON 内容类型，拒绝压缩请求，限制请求体并检查 UTF-8。会话令牌不放入 URL、浏览器存储或日志。设计参考 [OWASP 的跨站请求防护说明](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html)。

这些限制用于本地可信持有者的工作流程，不构成用户登录、加密传输或公共服务的访问控制体系。同一操作系统账户下的其他程序仍可能读取文件或访问回环服务；不能把本机接口直接暴露到局域网或公网。需要多用户和远程部署时，应另行设计身份、权限、传输和审计。

本地账本也不防止管理员复制、删除或回滚文件。不得通过重新创建项目规避相关发布的累计开销；跨设备账本同步与防回滚均未实现。完整边界见[隐私模型](PRIVACY_MODEL.md)和[发布账本](RELEASE_LEDGER.md)。

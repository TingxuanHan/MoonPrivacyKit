# MoonPrivacyKit 项目申报书

**项目名称：**MoonPrivacyKit（隐私工具箱）  
**项目方向：**MoonBit 通用工具库／隐私保护与数据处理  
**项目性质：**原创开发，参考公开方法；非现有项目的整体移植  
**开源许可证：**Apache-2.0  
**GitHub 仓库：**https://github.com/TingxuanHan/MoonPrivacyKit

## 项目简介与通用性

MoonPrivacyKit 致力于建设持续扩展、统一易用的隐私保护工具平台。面向问卷发起者、真实数据持有者与应用开发者，围绕调查收集、数据处理、统计发布和协作分析等实际需求，逐步提供可独立使用、也可衔接组合的隐私工具与完整方案，降低选择、配置和使用隐私工具的门槛。

项目以 MoonBit 构建可复用核心库，配套中文工作台与开发接口，为不同工具建立一致的操作方式、配置约定和结果说明。用户从实际任务出发选用工具，在适用条件满足时复用数据描述、字段规则与处理结果，组合处理步骤或切换方案，减少重复学习、配置和格式转换，使隐私保护更容易融入日常工作。

## 预期使用场景

1. **收集敏感意见：**组织者创建满意度或意见问卷；参与者通过本地差分隐私（LDP）随机化选择题答案后提交；组织者汇总受保护回答，估计各选项比例并查看误差范围，用于了解群体意见。
2. **处理真实数据并发布分析：**数据持有者导入已掌握或收集的 CSV／JSON，移除无需保留的敏感字段并复核；对外提供人数、类别分布时，在可信环境内限制每人贡献，经中心化差分隐私（CDP）处理后导出报告，报告不附带原始明细。
3. **跨团队联合统计（后续）：**多个课题组保留各自原始明细，通过安全多方计算汇总样本与指标；需核对样本重叠时，仅计算交集数量；对外报告再按约定实施差分隐私保护，支持共同分析而无需集中原始数据。
4. **按需组合与切换工具（后续）：**使用者先处理数据字段，再衔接统计报告工具；需要多方合作时，切换至联合统计方案，复用兼容的字段规则、统计口径与报告模板，查看所需配置及保护条件的变化。

## 本月拟实现的核心功能与验收目标

1. **隐私核心与效果评估：**实现二元／多选一随机响应及中心化差分隐私计数、预设类别直方图，分别校验参数、核算预算并评估误差；通过边界测试与可复现模拟检查机制和统计行为。
2. **隐私问卷闭环：**实现问卷配置、本地答案保护、受保护响应导出、汇总分析和报告生成；提供从填写到结果查看的可运行示例。首期以文件交换完成收集，验证原始答案不进入响应文件或日志。
3. **真实数据处理与统计发布：**实现 CSV／JSON 敏感字段删除、预览与导出，以及可信数据持有方侧的差分隐私统计报告；限定每人贡献，校准查询敏感度，累计核算发布预算并拒绝超预算请求，验证处理记录不泄露原值、报告不输出明细。

## 持续建设与项目特色

后续持续开发数据泛化、样本重叠核对、跨团队统计、应用统计接入、加密数据委托分析等实用工具，配套方案选择向导和可复用流程模板。各工具遵循统一的输入输出与配置约定，可按需独立使用或衔接；新增工具沿用熟悉的操作流程，方案切换时检查兼容性并保留相关保护记录，逐步形成便于扩展的隐私工具体系。

技术上按任务选用差分隐私、安全多方计算（MPC）、隐私求交（PSI），后续评估同态加密（HE）和零知识证明（ZKP）。本月聚焦上述三个目标，其余工具与通用衔接能力分阶段建设。字段处理不保证完全匿名；方案切换须重新核对信任条件，延续适用的隐私开销记录。DP 方法参考 [OpenDP](https://github.com/opendp/opendp)（MIT），以 MoonBit 独立实现；详见[工具与技术规划](TECHNOLOGY_PLAN.md)及[参考资料](REFERENCES.md)。

# MoonPrivacyKit 项目申报书

**项目名称：**MoonPrivacyKit（隐私工具箱）  
**项目方向：**MoonBit 通用工具库／隐私保护与数据处理  
**项目性质：**原创开发，参考公开方法；非现有项目的整体移植  
**开源许可证：**Apache-2.0  
**GitHub 仓库：**https://github.com/TingxuanHan/MoonPrivacyKit

## 项目简介与通用性

MoonPrivacyKit 面向问卷发起者、数据使用者和应用开发者，拟提供一套覆盖数据收集、处理与分享的隐私保护工具。项目以 MoonBit 实现可复用的核心库，配套本地工作台，让使用者能够开展保护个人回答的问卷调查、处理待分享文件中的敏感字段，并评估保护强度对统计结果的影响。核心能力通过统一接口复用，适用于校园调查、团队反馈、研究数据共享及应用统计，不依赖特定行业或单一业务系统。

## 预期使用场景

1. **收集敏感意见：**组织者创建满意度或意见问卷；参与者在本地对选择题答案进行随机化后提交；组织者汇总受保护回答，估计各选项比例并查看误差范围，用于了解群体意见。
2. **分享业务或研究资料：**使用者导入 CSV／JSON 文件，选择姓名、联系方式等字段的删除或遮盖规则，在本地预览、复核并导出处理后的文件及处理记录，减少资料交付时的个人信息暴露。
3. **评估调查方案：**发起者输入预计人数、题目数量和期望精度，比较不同保护配置下的统计误差及累计隐私开销，据此调整样本量或题目设置，并导出可复用的调查方案。

## 本月核心功能与验收目标

1. **隐私核心与效果评估：**实现二元／多选一随机响应、参数校验、多题隐私开销核算、比例估计及误差界；通过边界测试和可复现的模拟实验检查机制与统计行为。
2. **隐私问卷闭环：**实现问卷配置、本地答案保护、受保护响应导出、汇总分析和报告生成；提供从填写到结果查看的可运行示例。首期以文件交换完成收集，验证原始答案不进入响应文件或日志。
3. **本地文件脱敏：**实现 CSV／JSON 字段删除与遮盖、结果预览和文件导出；提供命令行或工作台入口，验证特殊字符、缺失字段及处理记录不泄露原值。

## 持续建设与参考说明

后续逐步扩展在线问卷服务、应用统计 SDK、重复采集管理及更多数据源，持续维护接口、文档与回归测试。随机响应参考 [OpenDP](https://github.com/opendp/opendp)（MIT）公开方法，核心代码拟采用 MoonBit 独立实现。项目特色在于连接保护配置、实际处理和效果解释，而非提出新的隐私算法。回答保护不等同于隐藏参与身份；字段脱敏也不承诺消除全部重新识别风险。

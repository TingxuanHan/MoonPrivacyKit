# MoonPrivacyKit 项目申报书

项目方向：MoonBit 通用工具库、隐私保护与数据处理

项目性质：原创开发，参考公开方法，非现有项目整体移植

开源许可证：Apache-2.0

项目仓库：[MoonPrivacyKit](https://github.com/TingxuanHan/MoonPrivacyKit)

## 一、项目简介

MoonPrivacyKit（隐私工具箱）面向问卷发起者、数据持有者和应用开发者，建设统一的隐私保护工具平台。项目从隐私问卷和真实数据处理起步，围绕统计发布、协作分析等需求，持续开发实用工具与完整方案。

项目以 MoonBit 开发可复用核心库，配套中文工作台和开发接口。不同工具采用一致的操作方式和配置约定，用户可按需选用、组合和切换方案，复用兼容的配置与处理结果，减少重复学习和手工转换，让隐私保护更容易融入日常工作。

## 二、预期使用场景

1. **敏感意见调查。**组织者创建问卷，参与者在本地通过随机响应保护选择题答案后提交。组织者汇总受保护回答，估计各选项比例并查看误差范围，用于了解群体意见。

2. **真实数据处理与分析发布。**数据持有者导入 CSV 或 JSON，按用途删除无需保留的敏感字段，复核后导出。需要对外提供人数、类别分布等分析结果时，在可信环境内限定每人贡献，生成不含原始明细的差分隐私统计报告。

3. **跨团队协作（后续）。**多个课题组保留各自原始数据，通过样本重叠核对与联合统计工具生成受保护的群体报告。从单方分析转向协作分析时，可复用兼容的字段规则、统计口径和报告模板，减少重新配置。

## 三、本月核心功能与验收目标

1. **核心机制与效果评估。**实现二元及多选一随机响应，以及中心化差分隐私计数和预设类别直方图，提供可复用接口。完成参数校验、机制预算核算与误差评估，通过边界测试和可复现模拟检查机制与统计行为。

2. **隐私问卷完整流程。**实现问卷配置、本地答案保护、受保护响应导出、汇总分析与报告生成，提供从填写到结果查看的可运行示例。首期采用文件交换收集响应，验证原始答案不写入响应文件和日志。

3. **真实数据处理与统计发布。**实现 CSV、JSON 敏感字段删除、预览与导出，接入核心统计接口，在可信数据持有方侧生成报告。限定每人贡献、校准查询敏感度，累计核算发布预算并拒绝超预算请求；验证处理记录不泄露原值、报告不输出明细。

## 四、持续建设

后续根据实际使用需求，逐步增加数据泛化、样本重叠核对、跨团队统计、应用统计接入和加密数据委托分析等工具，提供方案选择向导与可复用流程模板。差分隐私、安全多方计算和隐私求交等技术按任务需要选用，为具体功能提供支撑。

新增工具沿用统一约定，衔接或切换方案时核对兼容性与信任条件，保留适用的隐私预算记录。本月聚焦上述三个目标，其余工具与通用衔接能力分阶段建设。仅删除敏感字段不能保证匿名性；差分隐私方法参考 [OpenDP](https://github.com/opendp/opendp)（MIT），以 MoonBit 独立实现。

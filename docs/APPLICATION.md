# MoonPrivacyKit 项目申报书

**项目名称：**MoonPrivacyKit（隐私工具箱）  
**项目方向：**MoonBit 通用工具库／隐私保护与数据处理  
**项目性质：**原创开发，参考公开方法；非现有项目的整体移植  
**开源许可证：**Apache-2.0  
**GitHub 仓库：**https://github.com/TingxuanHan/MoonPrivacyKit

## 项目简介与通用性

MoonPrivacyKit 面向问卷发起者、数据持有者和应用开发者，拟提供覆盖数据收集、敏感字段处理与统计结果发布的隐私保护工具。项目以 MoonBit 实现核心库，配套本地工作台：收集问卷时采用本地差分隐私保护个人回答；处理已掌握或收集的真实数据时，移除无需保留的敏感字段；对外提供分析结果时，采用中心化差分隐私（Central Differential Privacy，CDP）保护统计输出。核心接口可复用于校园调查、团队反馈、研究数据分析及应用统计，不依赖特定行业。

## 预期使用场景

1. **收集敏感意见：**组织者创建满意度或意见问卷；参与者在本地对选择题答案进行随机化后提交；组织者汇总受保护回答，估计各选项比例并查看误差范围，用于了解群体意见。
2. **真实数据处理与分析发布：**数据持有者导入已掌握或收集的 CSV／JSON 数据，删除姓名、联系方式等无需保留的敏感字段并复核明细；需要向他人提供人数、类别分布等分析结果时，在可信环境内限制每人贡献、设置隐私预算，经中心化差分隐私处理后导出统计报告，报告不附带原始明细。
3. **评估保护方案：**使用者根据数据规模、统计任务与期望精度，比较相应保护配置的误差及累计隐私开销，据此调整问卷、样本量或统计发布方案，并导出可复用配置。

## 本月拟实现的核心功能与验收目标

1. **隐私核心与效果评估：**实现二元／多选一随机响应及中心化差分隐私计数、预设类别直方图，分别校验参数、核算预算并评估误差；通过边界测试与可复现模拟检查机制和统计行为。
2. **隐私问卷闭环：**实现问卷配置、本地答案保护、受保护响应导出、汇总分析和报告生成；提供从填写到结果查看的可运行示例。首期以文件交换完成收集，验证原始答案不进入响应文件或日志。
3. **真实数据处理与统计发布：**实现 CSV／JSON 敏感字段删除、预览与导出，以及可信数据持有方侧的差分隐私统计报告；限定每人贡献，校准查询敏感度，累计核算发布预算并拒绝超预算请求，验证处理记录不泄露原值、报告不输出明细。

## 持续建设与参考说明

后续扩展在线问卷服务、应用统计 SDK、更多统计任务与数据源。随机响应与中心化统计机制参考 [OpenDP](https://github.com/opendp/opendp)（MIT）公开方法，采用 MoonBit 独立实现。项目侧重保护配置、实际处理与效果解释。字段移除不保证完全匿名；CDP 依赖可信数据持有方，保护对外发布结果，不替代原始数据的访问控制。

# 处理方案比较与跨版本联合检查

状态：2026-10-16 规划，尚未实现。本文定义两个新增工具的首版范围、实际用途和验收条件；现有问卷、字段处理、统计账本和可读报告继续作为工作流基础。

## 1. 处理方案比较器

### 要解决的问题

删除姓名后，年龄、部门和日期等字段的组合仍可能把某条记录单独区分出来；把所有字段删除又会使数据失去用途。工具帮助可信数据持有者比较有限候选，查看风险指标的变化与保留信息的代价。它不自动认证数据安全，也不自动批准明细对外发布。

例如，使用者先设定年龄五岁／十岁分段、日期保留到月／年的候选，再比较各组合中小分组的记录比例和泛化程度。工具按用户的限制列出合适的候选，说明哪一项要求未满足，而不是只给一个缺乏解释的总分。

### 输入与计算

- 输入一份受控 CSV／JSON，明确一行代表什么；首版按记录计算，组内有 k 条记录不自动表示有 k 个不同的人。重复记录可能放大组大小；需要按人评价时先由持有者提供可靠的对应关系，不能自动推断。
- 用户指定准标识字段、必须保留的字段、期望最小组大小 k，以及预先定义的字段处理候选；首版最多枚举 64 个候选，不从私有取值自动生成分段边界。
- 对每个候选，以处理后的准标识元组建立分组，计算最小组大小、唯一记录比例和低于 k 的记录比例；缺失值单独标记并报告，不把缺失视为天然安全。
- 展示每列保留／遮盖／删除状态、保留记录比例、年龄区间跨度和日期精度。对有公开层级的字段，另计算归一化泛化损失；不以无法说明含义的统一分值替代这些明细指标。
- 根据使用者的明确限制筛选候选，展示风险指标与信息损失互不同时更差的候选集合，并以确定规则排序。搜索只针对给定候选，不声称全局最优。
- 首版不自动删除不达标行，不自动改写原文件。选择候选后仍需复核，输出配置和受控副本。

### 复用与新增工作

敏感内容扫描优先复用 moon_scrub；年龄、日期转换复用本项目已有字段模板。新增 MoonBit 模块负责候选展开、组合分组、指标计算、约束筛选和解释，工作台负责比较与明确应用。算法参考 ARX 的方案探索与可用性评估思想，不移植其整个 Java 框架，不把 k-匿名或多指标比较宣称为新算法。

### 验收

以可手算的虚构表验证分组、重复记录、缺失值、区间端点、保留率和损失指标；穷举小规模候选核对筛选及排序。覆盖无可行方案、候选超限、无效规则和原配置不变等情况。浏览器与 CLI 使用相同核心，比较过程不发布统计、不扣预算、不自动上传数据。

## 2. 跨版本联合检查

### 要解决的问题

单独查看每次导出时，某些字段组合可能都不稀有；如果同一人的两次记录可以关联，两个版本的不同字段合起来可能把记录进一步区分。工具用于持有者在周期交付前做保守检查，补充单次处理检查，而不是模拟所有现实攻击。

一个四行的虚构例子：第一版公开某属性的分组为 `{1,2}`、`{3,4}`，第二版公开另一属性的分组为 `{1,3}`、`{2,4}`。两版各自最小组大小都是 2；假设攻击者能够正确关联同一个人的行，联合后的组合均只出现一次。工具须能识别这一变化，同时明确“行可关联”是输入假设，不证明攻击者现实中一定能够关联。

### 首版范围

- 仅支持同一群体的两版表、同一粒度的一人一行，以及持有者提供的可靠私有行对应；重复身份、缺失对应、增删群体或语义不明的字段先拒绝联查，不作无风险结论。
- 使用者声明两版中哪些字段可被接收方观察，并确认保守的行可关联假设。对应标识只用于本地计算，不进入面向接收方的输出。
- 分别计算单版可见字段元组和两版合并元组的分组，展示组大小下降数量、新增低于 k 的记录比例及发生变化的字段组合；不把组大小直接表述为真实重识别概率。
- 首版只接收用户主动提供的文件，不后台保存原表，不自动建立整份明细历史副本。检查结果和对应关系属于受控内部资料，不进入公开 HTML 统计报告。
- 无关联关系时不猜测身份；不能把“未能联查”显示成“通过”。

### 验收

覆盖上述四行反例、同版重复输入、行序打乱但对应不变、已删除字段无法恢复，以及缺失／重复对应时的拒绝行为。测试私有标识不进入报告、日志或浏览器存储，修改任一输入后旧结果失效。联合检查不调用随机机制、不操作发布账本。

## 3. 与差分隐私统计的衔接限制

这两个工具均读取私有数据，精确指标、可行性结论和选出的方案本身可能泄露信息，默认只供可信持有者使用。

根据私有数据挑选分段、字段或类别后，不能仅因后续给计数加噪就沿用原有差分隐私保证。人工点击确认也不能把私有选择变成公开先验。首版保持评估与公开统计配置分离：正式统计沿用事先确定、独立于私有评估结果的规则；私有评估选择结果不得直接转入有保证的发布流程。

需要发布风险指标或将私有优化自动接入统计时，须另行设计有界敏感度的私有选择与预算组合，并验证数据相关预处理是否改变其他人的贡献。此项不计入首版完成范围。

k-匿名类诊断只覆盖所选字段和记录范围，不防止所有背景知识、属性推断或成员推断，不等于差分隐私，也不替代用途授权或合规判断。相关风险背景见 [NIST IR 8053](https://csrc.nist.gov/pubs/ir/8053/final)。

## 后续独立工具

后续建设多团队安全求和与样本重叠核对，分别采用经过审查的 MPC 与 PSI 后端。安全求和先限制为三计算方、半诚实且至多一方腐化、有界整数输入；精确总量的泄露与计算过程保护分开说明。通信保护、退出处理和结果开放需单独验收，不将本机多进程演示写成生产部署。

在此基础上再研究分布式加噪与联合差分隐私报告；样本重叠规模也不默认可公开。具体长期约束沿用[工具与技术规划](TECHNOLOGY_PLAN.md)。

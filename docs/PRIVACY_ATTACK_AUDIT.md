# 隐私泄露实测

本工具对一份已固定的分类合成数据进行成员推断和敏感属性推断，帮助持有者发现发布风险，并比较最多三份候选结果。计算由 MoonBit 完成，浏览器和命令行使用同一核心。它是内部攻击评估，不是匿名认证、差分隐私证明或 ε 估计器。

## 使用流程

在“发布检查 → 泄露实测”打开工具，或从已保存的合成结果点击“评估这份数据的泄露风险”。后一入口只带入已有结果与字段设置，不重新生成、不写账本、不消耗发布预算。

1. 准备参与生成的原始成员表，以及未参与生成、来自可比较人群的独立对照表。两表一人一行，使用相同的稳定人员标识规则，各 20–2,000 人。不同人员允许有相同特征；同一人不得通过改编号重复出现。
2. 导入 1–3 份待测表或完整生成记录。候选必须对应同一成员范围；工具不能自动证明文件来源和真实参与关系。可使用“载入虚构泄露示例”先体验完整流程。
3. 指定攻击者已知的 1–5 个分类字段、1 个敏感字段和它的 2–8 个类别。所有值必须是字符串。待测表必须恰好包含这些列；人员标识、额外列、未知类别、缺失值或重复键都会阻止评估，不静默忽略。
4. 在查看结果前固定分组种子与字段定义。工具将成员、对照分别分为约一半校准、一半测试，展示成员命中率、未参与者误报率、属性准确率、基线及区间。输入改变后，旧结果和下载入口立即失效。
5. 按内部资料保存报告。报告不含原始单元格、人员标识、逐人预测或原文件名，但汇总分数仍由私有数据计算，不能作为受保护统计公开。

首版最多 5,000 行待测数据，每份输入文本不超过 2,000,000 个字符；距离比较工作量有 2,000 万次上限，浏览器计算另有 30 秒超时。超限只返回原因，不给安全结论。原表允许有未选列，但待测表不允许有未检查列。JSON 表为对象数组，或导入本项目的完整生成记录；后者直接读取其中的类别数组，不信任记录自述的隐私证明。

本项目 CSV 导出会给公式样式文本加前缀。为保持类别原义，评估时优先使用完整生成记录；工具不会自动去掉任意 CSV 文本前缀。

## 两项攻击与对照

| 任务 | 使用的信息 | 校准与测试方式 |
| --- | --- | --- |
| 成员推断 | 假设攻击者知道目标的全部所选字段，包括敏感字段，但不知道此人是否参与生成 | 计算目标与待测表的最小汉明距离。在校准成员和校准对照上枚举阈值，以命中率减误报率最大为准；并列选择最小阈值，允许阈值 −1（全部判为未参与）。锁定阈值后只用独立测试组计分 |
| 属性推断 | 假设攻击者知道目标的已知字段，但不知道敏感字段值 | 按已知字段找最近记录，对最近记录的敏感类别多数表决，并列使用事先声明的类别顺序。只在测试成员和测试对照上评估；基线始终预测校准对照中最多的敏感类别 |

这两项攻击的知识假设不同，不能把成员推断中的敏感值提供给属性预测器。属性预测器不使用目标的真实敏感标签；真实标签只用于计分。属性预测优于全局多数基线，仍可能只利用群体规律，不证明泄露了个体训练记录。

成员优势为测试命中率减测试误报率；平衡准确率为 `(命中率 + 1 − 误报率) / 2`，无区分能力基线为 0.5。成员与对照数不相等时也分别归一化。结果不截断负优势，不把单独较高的准确率当作泄露证据。

单个比例使用近似 95% Wilson 区间，零次或全部成功仍保留不确定性。差值使用两个近似 97.5% Wilson 区间的保守差构造：`[L1 − U2, U1 − L2]`。这是 Bonferroni 分配下的近似区间，不是精确覆盖保证。它们只针对一份固定发布、既定评估设计和可视作独立样本的群体，不是对所有候选、攻击和种子的同时保证，也不能量化生成算法跨多次随机运行的最坏隐私损失。

成员与对照先按人员标识的 UTF-16 字典序排序，再使用固定种子的 Park–Miller / Fisher–Yates 分组；有界抽取采用拒绝采样。种子只用于可复现的实验拆分，不是隐私机制随机源。每组前 `floor(n/2)` 条用于校准，其余测试。对照种子为成员种子加一，最大种子时回到一。排序和分组均不使用特征、敏感标签或攻击分数；同一输入与种子在调整行顺序后仍产生相同结果。

## 如何解释结果

- 复制型虚构反例应表现为成员推断优势；它只用于检查功能，不代表真实数据的实测结果。
- 同分布的无区分反例会返回无优势或包含零的区间。攻击能力不足、小样本、相似人群或保守区间都可能造成证据不足，不能据此判定匿名。
- 人群来源、时间或采集方式不同，也能造成成员与对照分数不同。必须复核这种混杂，不能把分布偏移直接解释为记忆或隐私泄露。
- 在同一测试集上反复选择种子、字段、模型或候选，会使最终分数失去独立验证意义。正式比较需预先确定方案，并为后续选择保留新的测试集。
- 报告读取原始私有数据，不属于“只处理 DP 结果”的后处理。对外发布报告、依据私有分数选择新的公开输出，均不能自动继承原合成数据的 DP 保证。本节点不执行这样的发布或自动选参。

## 命令行与接口

```sh
node cli/main.mjs audit-synthetic examples/privacy-attack-plan.json private-data/members.csv private-data/nonmembers.csv private-data/synthetic-record.json private-data/attack-report.json
```

输入表扩展名须为 `.csv` 或 `.json`，输出路径必须不存在。退出码 0 只表示评估完成，不表示安全；校验、规模或文件错误返回非零，不生成报告。评估不会建立或重置账本。输入配置示例见 [privacy-attack-plan.json](../examples/privacy-attack-plan.json)，虚构数据见 [privacy-attack-demo.json](../examples/privacy-attack-demo.json)。

```js
import { evaluatePrivacyAttack, parsePrivacyAttackPlan } from './runtime/privacy-attack.mjs';
const report = evaluatePrivacyAttack({
  config: parsePrivacyAttackPlan(configText),
  members: { format: 'csv', input: memberText },
  nonmembers: { format: 'csv', input: controlText },
  released: { format: 'json', input: savedSyntheticText },
});
```

MoonBit 核心为 `evaluate_privacy_attack(request : Json) -> Json raise KitError`。浏览器通过独立 Worker 计算，不向本机 API 或外部服务发送评估表格；表格、配置和报告不写浏览器存储。页面刷新后需重新选择文件，明确下载的内部报告除外。

## 参考关系与 MoonBit 差异

核对日期：2026-10-18。方法参考 [TAPAS](https://github.com/alan-turing-institute/tapas/tree/a7069d7e040828db0da174d1b003fa03a98e5453)（MIT）及其[攻击库说明](https://tapas-privacy.readthedocs.io/en/latest/library-of-attacks.html)。TAPAS 已有近邻成员推断、属性推断和影子建模等攻击；本节点独立实现受限分类评估，不复制代码，不声称迁移完整 TAPAS 或发明新攻击。区间公式参考 [NIST 二项比例区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。

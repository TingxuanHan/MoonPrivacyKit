# 当前问卷逐题精度评估

发放问卷前，先用预计人数检查每道题能达到的精度。题目的选项数和 ε 可以不同，评估直接复用问卷配置与采集计划，无需重新输入。

## 工作台流程

1. 在“创建问卷”编辑题目，或预览并应用场景模板。复核每题 ε 和计划采集次数。
2. 在“发放前检查”点击“评估当前问卷”。也可以在“效果评估”切换到“当前问卷”载入草稿。
3. 输入每次预计人数和目标误差，点击“评估这个方案”。例如目标为 5，表示比例误差不超过 ±5 个百分点。
4. 查看各题的误差条、达标状态和所需人数。整份问卷所需人数取各题要求的最大值。
5. 可导出评估，或返回调整问卷。修改题目、选项、ε、问卷标题或原计划次数后，旧结果及下载按钮失效；重新载入再评估。

JSON 保留完整数值供程序处理，“下载可读报告（HTML）”提供离线阅读和打印版本，两种格式对应同一份评估。自定义方案也使用相同的导出入口。报告区分无法估计、人数超限和已达标状态，详见[可读报告](READABLE_REPORTS.md)。

评估页的采集次数用于比较方案，修改它不会回写问卷编辑器。确认采用新次数后，应回到编辑器修改计划，再重新导出配置与参与说明。“自定义方案”继续支持所有题目使用相同选项数和 ε 的快速比较。

## 如何阅读结果

| 结果 | 含义 |
| --- | --- |
| 达到目标 | 当前预计人数下，本题的保守误差界不超过设定目标 |
| 未达目标 | 查看本题所需人数，再复核人数、目标误差、选项和保护参数 |
| 无统计信号 | ε 为 0 或小到有限精度机制无法保留信号，单纯增加人数不能解决 |
| 所需人数超过 1,000 万 | 超出当前规划范围，不返回虚假的有限人数 |

同一题的图条越短，保守误差界越小。所有图条使用 0 至 100 百分点刻度，竖线表示目标；超过 100 的误差保留完整数值说明，不把截断图条当成实际数值。

评估沿用随机响应的 Hoeffding 界，将失败概率 `0.05` 分配给各题，再在每题的选项间分配。95% 同时范围覆盖的是**单次采集的全部题目与选项**，并非全部重复批次。误差针对该批实际回答的比例，依赖各参与者随机化独立；不消除选择偏差、虚假回答或非代表性样本带来的偏差。该界通常较保守，不能将“达到目标”理解为保证调查结论准确。

每次人数须为 1 至 10,000,000 的整数，计划次数须为 1 至 10,000 的整数。核心的目标误差为大于 0、小于 1 的比例；工作台用 0.01 至 99 百分点输入。重复采集只增加每人的组合隐私开销，不自动增加每次独立参与者人数，也不实施参与次数限制。

## 命令行与接口

构建后在仓库根目录运行，输出文件须不存在：

```sh
node cli/main.mjs assess-survey examples/survey.json 1000 5 3 reports/assessment.json
```

参数依次是问卷配置、每次人数、目标误差百分点、计划采集次数和新评估文件。父目录须已存在；该命令不创建回答、不操作统计账本。

```js
import { assessSurvey } from './runtime/survey-assessment.mjs';

const report = await assessSurvey(survey, {
  samples: 1000,
  targetRadius: 0.05, // SDK 使用比例，0.05 对应 5 个百分点。
  collections: 3,
});
```

MoonBit 可直接调用 `assess_survey(survey, 1000, 0.05, collections=3)`；JSON 接口操作为 `assessSurvey`，字段为 `survey`、`samples`、`target_radius` 和 `collections`。

JavaScript 返回的报告类型为 `moonprivacykit/survey-assessment`、版本为 1，包含问卷编号、标题、SHA-256 配置指纹和评估结果。结果按问卷顺序列出每题的编号、标题、选项数、ε、误差半径、所需人数和达标状态。无有限人数时 `required_samples` 为 `null`，原因是 `no_signal` 或 `above_limit`；正常结果的 `reason` 为空字符串。无统计信号时该题 `radius` 也为 `null`。SDK 在计算指纹前保存配置快照，并冻结返回对象，调用后改变原对象不改动报告。

## 使用边界

这是一份规划结果，既不是参与记录，也不是发布预算凭证。评估不读取个人回答、不随机采样、不扣减账本预算；重复导出复用同一结果。问卷题目与标题会出现在报告中，配置文本不要包含个人信息。配置指纹用于对应原问卷，不证明发起者身份或实际执行次数。刷新会清除未下载的评估；当前尚无评估历史管理或通用方案转换引擎。

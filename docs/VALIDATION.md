两个子进程同时执行同一请求时，只保存一份结果并扣费一次；两个不同请求争用仅够一次发布的预算时，只有一个成功。分别在 SQLite 提交前和提交后终止专用测试子进程，验证了未提交事务回滚，以及已提交结果跨进程恢复且不重复扣费。测试没有终止用户程序。

第六个节点新增 8 项 MoonBit 测试、8 项 Node 测试与 4 组浏览器测试。模板要求全部列显式配置，校验未知／重复键、版本、规则、名称和数据结构；新增、缺失列会阻止旧模板应用。CSV／JSON 可复用相同规则，列顺序变化不改变规则含义，兼容检查不调用随机源或操作账本。

统计衔接排除删除、遮盖和 CSV 公式文本化改写的列，包括原值恰等于遮盖占位符、后续记录才出现改写、列名转义和转义后表头碰撞。重复 JSON 键在处理前被拒绝，即使出现在将被删除的嵌套内容中。CSV 多个双引号曾只转义首个，现已修复；新增往返测试验证列名及带多个引号、逗号和换行的值保持一致。

SDK 通过原输入与规则重新核对可用统计字段，等价 CSV、JSON 和直接原表统计可复用同一报告；模板改名不产生新结果，改变人员映射会触发冲突。新编号累计计费，超预算被拒绝；缺失账本、错误字段、无效模板及未提供请求编号不创建账本、不扣费。命令行验证了只检查、导出、处理记录、覆盖拒绝和无效 UTF-8。

浏览器实际完成字段配置导出、刷新后导入、CSV 到 JSON 复用、预览后明确应用，以及处理结果转入统计后发布。转入前后检查预算一致且没有发布请求；正式发布只提交处理后的表格。修改字段规则使脱敏预览失效，但不改变已转入的副本。已完成报告不会被转入覆盖，待确认且保有原输入时禁止替换；刷新后重新处理并转入可沿用原编号重试，只扣减一次预算。

新增字段、无效版本、重复键和无效编码均可恢复，原有规则不被模板覆盖；统计模板不能重新选用已删除或改写的列。桌面与 390 像素截图已复核，长名称和恶意标签按文本显示，无横向溢出，配置导出支持键盘操作。未向远程服务发送数据，浏览器存储未出现测试明细。本节点尚未实现泛化规则、可信处理历史文件或通用流程引擎。

## 年龄分段与日期降精度节点

SDK 拒绝将泛化列、遮盖列或改写后的列作为人员标识。年龄与日期可作类别，但缺少公开类别时拒绝发布。等价 CSV／JSON、同一区间内年龄变化及未用于查询的日期变化复用原报告；改变人员、实际映射或类别定义触发同编号冲突。新编号持续累计开销，超预算被拒绝，无效数据不修改账本。命令行验证了新模板检查、导出、只含数量的处理记录、覆盖拒绝及无效数据不生成输出文件。

浏览器完成年龄／日期条件参数、键盘进入、版本 2 导出后跨 CSV／JSON 复用、无效参数和数据恢复，以及泛化类别转入统计。身份选项不含泛化列，统计模板也无法绕过；年龄类别只在明确点击后由公开配置填写，选择日期不会提取月份或覆盖现有类别。模拟服务已经保存报告但响应中断后，同一输入和编号重试返回相同报告、只扣减一次预算。

## 原有功能回归

问卷可编辑和导出，随后载入、填写、随机化并下载；重复下载字节相同；原始选择在生成后从表单移除。同一文件重复导入只计一次，报告不含响应编号。无效配置、分数形式的类别编号及不匹配的配置指纹被拒绝。

CSV 与 JSON 指定字段可删除／遮盖，结果与处理记录可下载。修改规则后旧预览失效。CSV 覆盖逗号、引用字段、引号、换行、空值和中文。处理记录不含原值；CLI 拒绝覆盖原文件、已有结果和已有处理记录。

浏览器测试未观察到向本机源以外发出的请求，未出现页面脚本错误。问卷、脱敏和效果评估文件仍在浏览器内处理；隐私统计新增受限的回环接口，在本机服务侧发布。本地服务只接受已定义操作，拒绝根路径 POST 和未列出的资源，包括 `.git/config`。

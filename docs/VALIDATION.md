## 中心化隐私统计节点

第一个开发节点新增 10 项 MoonBit 测试和 8 项 Node 测试。贡献上限作用于同一人在全部类别中的记录，移除一个人的全部记录后 L1 变化不超过该上限。空数据仍对每个预设类别取样；越界、分数类别、异常预算、过长标识及超限输入被拒绝，超出贡献上限的记录仍须通过校验。

小域穷举检查了整数噪声的概率分布、两端尾部累积和相邻概率比。宿主使用精确整数分数核对了 5 组贡献上限、每组 513 个预算值的保守校准。安全随机适配验证了拒绝采样、随机源不可用或抛错时不返回结果，以及不使用 `Math.random`。

固定种子的虚构数据测试分别执行 12,000 次计数与 3,000 次直方图发布，检查几何噪声的均值、二阶矩、零值和尾部频率，以及相对贡献裁剪后统计的同时误差界。检查均通过；有限模拟不构成新的隐私证明或真实数据效果结论。安全随机源的 `examples/central.mjs` 示例也已实际运行。

核心使用条件见[中心化隐私统计](CENTRAL_PRIVACY.md)。真实表格映射现已通过命令行和工作台与账本连接。

## 发布账本节点

第二个节点新增 3 项 MoonBit 测试和 12 项 Node 测试。精确预算累计覆盖了小数相加、预算恰好耗尽、越界状态及整数溢出拒绝。相同请求在预算用尽或安全随机源不可用时，仍可取回原结果；改变数据、顺序、类别含义、预算或贡献上限后沿用同一编号会被拒绝。

两个子进程同时执行同一请求时，只保存一份结果并扣费一次；两个不同请求争用仅够一次发布的预算时，只有一个成功。分别在 SQLite 提交前和提交后终止专用测试子进程，验证了未提交事务回滚，以及已提交结果跨进程恢复且不重复扣费。测试没有终止用户程序。

提交异常、随机源失败及报告写入失败均有独立测试。报告导出失败后，已提交结果可通过命令行再次导出；已有输出文件与账本不会被覆盖。检查账本文件和公开结果均未出现测试人员的原始标识，缓存结果意外修改会触发完整性校验错误。

本次运行使用 Node.js 24.18.0 内置 SQLite 3.53.1。没有开展断电、恶意管理员、数据库回滚、多设备同步或网络文件系统验证；这些不属于本节点完成范围。具体接口与边界见[发布预算与结果复用](RELEASE_LEDGER.md)。

## 真实表格统计节点

第三个节点新增 7 项 MoonBit 测试和 9 项 Node 测试。CSV 引号、换行、BOM、中文和带前导零的标识可正确映射；等价 JSON 保留相同的人员与类别序列。检查了按人跨类别裁剪、空表、字段数量与长度限制、缺失及错误类型、未知类别，以及转义后相同的重复 JSON 键。超出贡献上限的记录仍需通过校验，错误消息不回显原值。

从 CSV、JSON 和既有直接发布接口输入相同映射数据，均可复用同一次受保护结果；只修改未选择的列不另行发布，改变映射后的数据或类别定义则产生请求冲突。预算耗尽后可恢复原报告，即使安全随机源不可用也不会重新采样；新请求被拒绝。

命令行测试覆盖真实文件往返、无效 UTF-8、原文件和已有报告覆盖保护，以及报告写出失败后的恢复。校验失败不写报告、不扣预算。输出报告与账本文件均未出现测试人员标识、未选择的字段内容或字段映射，恢复结果与已提交结果一致。输入映射本身是私有中间处理，不构成差分隐私机制。

## 统计工作台节点

第四个节点新增 9 项 Node 测试和 5 组浏览器测试。历史分页校验顺序、边界、元信息和完整性，不增加预算；损坏的报告被拒绝。本机 API 验证了跨源请求、伪造 Host、缺少或错误会话令牌、非 JSON 请求、目录越界名称、无效 UTF-8、过大请求与任意文件访问均被拒绝。接口输出和账本文件中未出现测试人员标识或未选中的私有字段。

四个并发的相同 HTTP 发布得到同一报告、只扣费一次；服务重启后报告保持一致、旧会话令牌失效。无效表、请求冲突和预算不足没有增加报告数量或预算开销。API 限制服务于本机可信持有者场景，不构成完整的渗透测试或远程部署认证。

浏览器执行了项目创建、CSV 类别分布、JSON 类别分布、计数、误差预估、重复下载、历史恢复和项目切换。连续点击仅发送一次发布请求；在服务已提交但响应被中断的情况下，重试或刷新恢复都返回原报告，不重复扣费。在请求未送达、随后刷新且输入校验失败的情况下，仍保留原编号直到成功恢复或完成该请求。会话存储未出现测试原表或公开类别配置。

历史列表用 21 份虚构报告验证 20 条分页、加载更早记录和刷新；查看历史和重复下载保持预算不变。无效编码、重复表头、未知类别和预算不足均显示可操作的错误，允许修改后继续。恶意类别标签按文本展示，不创建可执行元素。

实际检查了桌面 1365 × 1000 与窄屏 390 × 844 的空状态、输入、报告、历史和错误截图；无横向溢出。成功后收起输入区，突出报告下载和剩余预算；长类别换行、数值及误差范围可见。键盘可从预算输入进入发布按钮，报告具有可聚焦区域和文字数值。测试截图只含虚构数据，保存于 `reports/ui/`。

## 原有功能回归

问卷可编辑和导出，随后载入、填写、随机化并下载；重复下载字节相同；原始选择在生成后从表单移除。同一文件重复导入只计一次，报告不含响应编号。无效配置、分数形式的类别编号及不匹配的配置指纹被拒绝。

CSV 与 JSON 指定字段可删除／遮盖，结果与处理记录可下载。修改规则后旧预览失效。CSV 覆盖逗号、引用字段、引号、换行、空值和中文。处理记录不含原值；CLI 拒绝覆盖原文件、已有结果和已有处理记录。

浏览器测试未观察到向本机源以外发出的请求，未出现页面脚本错误。问卷、脱敏和效果评估文件仍在浏览器内处理；隐私统计新增受限的回环接口，在本机服务侧发布。本地服务只接受已定义操作，拒绝根路径 POST 和未列出的资源，包括 `.git/config`。

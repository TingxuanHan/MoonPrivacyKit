## 已验证的用户行为

问卷可编辑和导出，随后载入、填写、随机化并下载；重复下载字节相同；原始选择在生成后从表单移除。同一文件重复导入只计一次，报告不含响应编号。无效配置、分数形式的类别编号及不匹配的配置指纹被拒绝。

CSV 与 JSON 指定字段可删除／遮盖，结果与处理记录可下载。修改规则后旧预览失效。CSV 覆盖逗号、引用字段、引号、换行、空值和中文。处理记录不含原值；CLI 拒绝覆盖原文件、已有结果和已有处理记录。

浏览器测试未观察到向本机源以外发出的请求，未出现页面脚本错误。文件通过浏览器文件 API 读取，没有上传接口。本地服务拒绝 POST 和未列出的路径，包括 `.git/config`；该检查不构成完整的渗透测试。

## 虚构数据评估

固定 1,000 个回答，种子 20261005，每个设置 50 次模拟。数值为比例误差，乘 100 可换成百分点。

| --- | ---: | ---: | ---: |
| 80% / 20% | 0.5 | 0.07337 | 0.19112 |
| 80% / 20% | 1 | 0.03509 | 0.10129 |
| 80% / 20% | 2 | 0.01528 | 0.06146 |
| 60% / 30% / 10% | 0.5 | 0.08036 | 0.27518 |
| 60% / 30% / 10% | 1 | 0.03677 | 0.13435 |
| 60% / 30% / 10% | 2 | 0.01469 | 0.07190 |

各设置的模拟中，所有选项同时落入区间的观测比例均为 100%；这是有限次模拟结果，**不是 100% 覆盖率保证**。理论保证依赖机制与独立性假设，Hoeffding 界通常较保守。模拟不验证密码学安全性，也不代表真实参与者数据。

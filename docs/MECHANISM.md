# 随机响应与误差界

## 有限随机机制 rr24-v1

令选项数量为 `k`，`M = 2^24`，整数阈值为 `a`。客户端独立生成一个 `[0,M)` 均匀整数和一个 `[0,k)` 均匀类别；前者小于 `a` 时保留回答，否则返回后者。候选类别包括原选项。

- 原选项被报告的概率：`p = a/M + (M-a)/(M*k)`。
- 其他任一选项被报告的概率：`q = (M-a)/(M*k)`。
- 最大概率比：`p/q = (M+(k-1)*a)/(M-a)`。
- 对应的隐私参数：`epsilon_effective = ln(p/q)`。

代码根据请求的 ε 计算整数阈值，向下取整后额外保留一个单位的余量，并检查实际参数不超过请求值。支持 2–256 个选项及 0–8 的 ε；ε 过小导致阈值为零时，仍可生成完全无信号的回答，但拒绝做比例估计。数值计算依赖 MoonBit 及宿主的浮点实现；当前没有独立安全审计或机器验证证明。

真实回答使用 Web Crypto 的 32 位安全随机数。高 24 位构成整数门控；类别通过拒绝采样生成，避免简单取模导致偏差。随机数、保留与否的分支及原始回答都不进入响应文件。基础库的 `randomize` 和 `randomizeBatch` 是由调用者提供均匀随机样本的底层接口；接入真实数据时应使用 `protectResponse` 安全适配器。

## 估计与不确定性

令收到的第 j 类比例为 `f_j`，校正后的比例为：

`theta_hat_j = (f_j - q) / (p - q)`。

原始估计无偏，但有限样本下可能小于 0 或大于 1。界面将显示值裁剪到 `[0,1]`；报告保留原始估计。裁剪后的各类显示比例之和不保证为 1，也不再是无偏估计。

对一个问题的全部 k 个选项，以失败概率 α 使用 Hoeffding 界与并合界：

`radius = sqrt(ln(2*k/alpha)/(2*n)) / (p-q)`。

区间是 `theta_hat ± radius` 与 `[0,1]` 的裁剪结果。包含多题时将总失败概率 0.05 均分到各题，因此整份问卷同时覆盖率至少为 95%，前提是保护随机数独立且采集过程满足模型假设。它刻画固定回答集合经随机化后的统计误差，也可在独立同分布抽样模型下用于总体比例；不纠正不诚实回答、选择偏差或灌票。

## 组合与重试

每人回答所有问题并参与全部采集时，按请求 ε 求和再乘采集次数。工具给出开销估计，不强制全球唯一参与次数。修改问卷、重新生成回答或跨设备参与都需要重新核算。

配置指纹使用规范化问卷 JSON 与机制版本的 SHA-256，绑定题目顺序、选项顺序和 ε。它用于发现配置不匹配，不是组织者身份认证。回答编号是独立的 128 位随机数；汇总时相同编号、相同内容去重，编号相同而内容不同则拒绝。重试必须复用原文件。

## 可复现评估

构建后运行 `node scripts/evaluate.mjs reports/evaluation.json`，输出二元与三元虚构总体、三个 ε 下的 RMSE、误差界与观测覆盖率。固定种子仅用于模拟。该实验检查实现行为和可用性，不能替代以上概率比分析或安全审计。

方法背景见 [OpenDP 随机响应说明](https://docs.opendp.org/en/stable/api/user-guide/measurements/randomized-response.html)。本实现使用独立编写的有限整数采样器，不是 OpenDP 的代码移植。

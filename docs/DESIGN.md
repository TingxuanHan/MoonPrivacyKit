# 工作台设计约定

发布检查增加“报表防反推”和“按人保护的多表统计”，协作工具增加“匿名参与凭证”和“联合统计”。沿用原生表单、绿色主操作和相邻文件导出。精确约束用可编辑类别与关系表单表达，求解在 Worker 中执行；修改输入后旧结论和导出失效。多表统计复用同一项目账本，待确认编号在刷新后恢复，历史与下载不重新采样。匿名凭证的私有状态、参与者密钥和原始回答不作为页面预览。联合统计区分参与方和接收方操作，精确合计旁明确输出保护的限制；文件重复下载复用同一加密份额。

“处理方案比较”复用用户在文件脱敏中保存的模板，先列风险、公开规则损失和保留信息，再明确导出副本；不自动跳转 DP 发布。内容扫描只给列名、类型与数量。两版联查先确认群体与可关联条件，再展示单版和联合分组变化；无法对应时给出错误，不展示通过。两项分析在 Worker 内运行，输入变化使旧结果失效；窄屏子导航换行。它们的分析记录属于内部资料，不使用公开统计报告的视觉承诺。

面向问卷发起者、填写者与真实数据持有者，主要对象是问卷配置、受保护回答、待处理文件、字段规则，以及带预算的统计项目和受保护报告。首要任务是选任务、完成输入、复核结果并导出。

采用原生 HTML 表单和小型 JavaScript 模块，复用 MoonBit 编译产物。当前复杂度不需要大型前端框架、多用户管理或远程状态缓存；以后增加在线协作时，应先定义身份、权限与数据流。

- 主导航放隐私问卷、文件脱敏、效果评估和隐私统计；问卷内区分创建、填写与汇总，统计内区分新发布和已有报告。
- 中文标签说明用户要做什么。ε 在影响保护强度的输入旁解释，内部消息格式不作为主要操作入口。
- 采用紧凑表单、浅色工作区和深绿色主操作，保持正常／错误／空状态一致，参考公共服务表单的标签与帮助方式。
- 移动端导航放在顶部，表单单列，主要操作全宽；结果允许换行，不压缩到不可读。
- 输入内容作为文本渲染；无第三方字体、跟踪脚本或远程资源。错误消息不得拼接私有文件内容。
- 文件或规则变化使旧结果失效；下载受保护回答复用已有生成结果。
- 控件具有可访问名称、键盘路径与明确状态。新增流程同步维护浏览器测试与窄屏检查。

当前视觉使用深绿主色（`#126957`）、浅绿工作区（`#f1f5f3`）、白色表单和清晰的边线，以系统字体保持离线可用。导航以工具图标配合文字，选中项同时改变边框、底色和字重。标题、字段、提示、结果数值有固定层级；主按钮用于执行，次按钮用于导出或配置复用，文字按钮用于返回和局部编辑。焦点使用可见轮廓，达标状态同时提供文字，不只依赖颜色。

宽屏问卷页将题目编辑与“发放前检查”分列，右侧集中采集计划、预算摘要、评估入口和配置导出；窄屏合并为单列。低矮视口取消摘要的粘性定位，避免遮挡操作。切换工具或问卷步骤回到页面顶部；页面宽度受限时表单与结果上下排列，不横向挤压。

效果评估分为“自定义方案”和“当前问卷”。当前问卷显示来源、题目数量、单次开销与原计划次数，避免重复填写题目参数；评估次数作为独立的比较条件，不回写编辑器。结果先给出是否达标，再逐题对照误差与目标。每条误差图使用相同的 0 至 100 百分点刻度，以竖线标记目标，并配有数值和可访问名称。无信号不绘制虚假误差条，超出刻度的值保留完整文字。

修改源问卷或采集计划时，收起旧评估及其下载按钮，提示重新载入；修改评估条件也需要重新计算。异步配置指纹尚未完成时改变输入，旧结果不能覆盖新状态。重复导出复用同一份评估，不重新采样、不触碰账本或待确认发布编号。

问卷汇总、两种评估和隐私统计共用报告下载组件：保留原 JSON 按钮，在相邻位置提供“下载可读报告（HTML）”及离线／打印提示。格式转换失败只在该结果旁说明，已有结果和 JSON 下载保留；源输入失效时两类下载一同收起。统计历史与恢复沿用同一入口，不额外提供容易误触的新发布按钮。

可读报告采用白底文档布局，沿用深绿标题线、系统字体、清晰的参数区和结果表；保护条件紧随结果，配置指纹放在文末。手机将表格按记录展开并保留每项标签，打印恢复表头与表格，避免依赖底色区分数值。比例显示两位小数，置信区间向外取整，原始精度仍由 JSON 保留；极小 ε 不显示为零。文件不使用脚本、外链字体、远程图片或动态生成时间，重复下载保持一致。

隐私统计先选择项目并展示剩余预算，再导入表格、选字段和保护参数，最后发布及下载。预算预估不访问个人记录、不取样；发布按钮明确展示本次开销。处理期间锁定有关控件，成功后收起输入区，将报告作为主要结果。“准备下一次发布”与“下载这份报告”使用不同按钮，避免将重新采样误作重复下载。

不确定的发布结果保留请求编号，优先恢复已提交报告。刷新后不保留原表，只允许恢复或用同一编号重试；已有编号发生输入冲突时不自动换编号。历史按每页 20 份加载，读取历史不消耗预算。长文件名、类别和错误说明可以换行；窄屏使用单列输入，图表配有文字数值和误差范围。

统计配置复用放在现有表单内，以折叠区域减少首次使用的干扰。导入先展示模板名称、统计参数和兼容性，公开类别可展开完整查看；用户明确应用后才替换表单。缺少字段、类型或类别不匹配时保留当前设置，并说明如何调整。保存配置与发布结果分开，导入导出都不创建请求编号、不修改账本。页面不显示原始数据或内部 JSON 作为主要预览。

流程与布局检查记录见 [VALIDATION.md](VALIDATION.md)。

字段配置复用沿用统计模板的折叠预览与明确应用方式，记录全部列的决策。新增／缺失字段时保留当前规则，并提示复核；不自动推断哪些列属于敏感信息。“用此结果继续统计”放在处理结果之后，与文件下载分开。先检查保留字段，再传递内存副本；统计页面说明来源和不可用字段，仍由用户确认统计口径后发布。当前发布未确认时保留原输入，避免切换工具覆盖重试所需状态。窄屏采用单列，规则及字段列表可展开，长名称按文本换行。

年龄分段与日期降精度的参数在选中对应规则后才展开；隐藏控件不参与提交或键盘路径。修改参数立即使旧预览失效，无效数据不跳过，错误不回显个人值。转入统计后分别提供身份和类别选项，泛化列标明“已泛化”且仅供类别选择；年龄区间由用户明确点击后从公开配置填写，不自动覆盖当前类别，日期范围不从私有记录推断。

问卷场景选择与模板保存放在创建表单的折叠区域。模板先展示全部问题、参数和累计开销，用户明确替换后才改变草稿并建立新问卷；取消和无效导入保留当前内容。编辑、导出配置与下载参与说明使用同一份问卷编号，删除其他问题不改变保留问题的编号。参与说明的下载与配置导出分开，提示二者须在修改后重新生成。

填写端显示单次与重复提交开销；更换文件先保留当前选择和受保护回答，确认后才清除。待确认时不能生成新回答，原回答仍能下载。生成期间锁定换文件操作；取消更换后恢复当前问卷。错误只说明格式或范围，不回显文件内容。模板选择成功后清除旧错误，手机上按钮与字段单列，预览问题列表可用键盘滚动。

# 工作台设计约定

面向问卷发起者、填写者与真实数据持有者，主要对象是问卷配置、受保护回答、待处理文件、字段规则，以及带预算的统计项目和受保护报告。首要任务是选任务、完成输入、复核结果并导出。

采用原生 HTML 表单和小型 JavaScript 模块，复用 MoonBit 编译产物。当前复杂度不需要大型前端框架、多用户管理或远程状态缓存；以后增加在线协作时，应先定义身份、权限与数据流。

- 主导航放隐私问卷、文件脱敏、效果评估和隐私统计；问卷内区分创建、填写与汇总，统计内区分新发布和已有报告。
- 中文标签说明用户要做什么。ε 在影响保护强度的输入旁解释，内部消息格式不作为主要操作入口。
- 采用紧凑表单、浅色工作区和深绿色主操作，保持正常／错误／空状态一致，参考公共服务表单的标签与帮助方式。
- 移动端导航放在顶部，表单单列，主要操作全宽；结果允许换行，不压缩到不可读。
- 输入内容作为文本渲染；无第三方字体、跟踪脚本或远程资源。错误消息不得拼接私有文件内容。
- 文件或规则变化使旧结果失效；下载受保护回答复用已有生成结果。
- 控件具有可访问名称、键盘路径与明确状态。新增流程同步维护浏览器测试与窄屏检查。

隐私统计先选择项目并展示剩余预算，再导入表格、选字段和保护参数，最后发布及下载。预算预估不访问个人记录、不取样；发布按钮明确展示本次开销。处理期间锁定有关控件，成功后收起输入区，将报告作为主要结果。“准备下一次发布”与“下载这份报告”使用不同按钮，避免将重新采样误作重复下载。

不确定的发布结果保留请求编号，优先恢复已提交报告。刷新后不保留原表，只允许恢复或用同一编号重试；已有编号发生输入冲突时不自动换编号。历史按每页 20 份加载，读取历史不消耗预算。长文件名、类别和错误说明可以换行；窄屏使用单列输入，图表配有文字数值和误差范围。

统计配置复用放在现有表单内，以折叠区域减少首次使用的干扰。导入先展示模板名称、统计参数和兼容性，公开类别可展开完整查看；用户明确应用后才替换表单。缺少字段、类型或类别不匹配时保留当前设置，并说明如何调整。保存配置与发布结果分开，导入导出都不创建请求编号、不修改账本。页面不显示原始数据或内部 JSON 作为主要预览。

流程与布局检查记录见 [VALIDATION.md](VALIDATION.md)。

字段配置复用沿用统计模板的折叠预览与明确应用方式，记录全部列的决策。新增／缺失字段时保留当前规则，并提示复核；不自动推断哪些列属于敏感信息。“用此结果继续统计”放在处理结果之后，与文件下载分开。先检查保留字段，再传递内存副本；统计页面说明来源和不可用字段，仍由用户确认统计口径后发布。当前发布未确认时保留原输入，避免切换工具覆盖重试所需状态。窄屏采用单列，规则及字段列表可展开，长名称按文本换行。

年龄分段与日期降精度的参数在选中对应规则后才展开；隐藏控件不参与提交或键盘路径。修改参数立即使旧预览失效，无效数据不跳过，错误不回显个人值。转入统计后分别提供身份和类别选项，泛化列标明“已泛化”且仅供类别选择；年龄区间由用户明确点击后从公开配置填写，不自动覆盖当前类别，日期范围不从私有记录推断。
